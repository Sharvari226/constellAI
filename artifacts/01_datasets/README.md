# Datasets
- Synthetic LEO scenarios: generated on the fly by constellai/evaluation/scenarios.py (deterministic per (stream, seed, index)). No files.
- ESA Kelvins Collision Avoidance Challenge CDMs: NOT redistributed. Download from Zenodo record 4463683 (Uriot et al., arXiv:2008.03069) and extract to data/esa_cdm/ (layout in the main README). esa_profile.txt is the profile of the files used.
- Vallado reference TLE: tests/physics_validation.
